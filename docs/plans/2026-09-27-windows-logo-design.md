# Windows 单色 Q 图标

状态：9146/9147 安装后用户反馈深色任务栏仍有黑字白边；9148 补上 Windows 注册输入源的默认资源，已正常升级安装并从同一位置的前后桌面截图确认系统 Q 的笔画为白色填充。实屏验证仅覆盖本机深色任务栏；已随 0.4.8（Windows 构建 9149）发布，发布包来自全部通过的同一次 CI。

用户希望去掉 Windows 蓝底白字图标，参考 macOS 菜单栏的简洁单色文字。采用透明底、深墨色 Q；字形为自绘椭圆环和短圆角斜尾，不依赖字体、渐变或阴影。白色方块底、方框描边会增加视觉负担，因此未采用。macOS 现有图标不在本次修改范围内。

Windows 应用文件与快捷方式使用 `windows/resources/RimeQ.ico`，包含 16、20、24、32、40、48、64、96、128、256 像素。每档独立超采样绘制；固定应用图标沿笔画保留细白轮廓，小尺寸略加强，用于不同背景。字母内孔和外围仍透明。固定 ICO 不会自动变成白字。

Windows 自己管理的输入源指示图标通过注册的 DLL 图标索引 0 提取，与托盘及 `ITfLangBarItemButton::GetIcon` 是三个不同入口。9147 漏改了这个入口；9148 将 TIP 的首个图标资源 101 改为纯白 `TaskbarQ.ico`，深色任务栏不再出现黑字加白边。该系统静态资源不宣称跟随浅色主题自动换色，自有托盘与菜单图标仍按下面的规则响应主题。

9146 安装后用户指出深灰任务栏上的黑字不正确，任务栏不再复用上述应用图标。托盘及 TSF 菜单 Q 改用独立 `TaskbarQ.ico` 字形，没有浅色描边；读取 `SystemUsesLightTheme`，深色任务栏用纯白、浅色用墨黑，高对比度沿用系统控件文字色。`AppsUseLightTheme` 只决定应用界面，不能决定任务栏颜色。中/A 也按同一任务栏配色绘制。

主题变化通过现有系统事件和隐藏窗口的主题广播触发刷新，不增加轮询或重新注册输入源。托盘替换图标时释放旧句柄，退出时取消系统事件订阅。任务栏 ICO 使用兼容 .NET Framework 的 DIB 帧，避免 `Icon(Stream)` 错读 PNG 帧。资源像素、混合主题及句柄回归不等同于真实任务栏视觉验收。

设置与安装器使用共享矢量 `windows/resources/Brand.xaml`，跟随已有 `TextColor` 资源，浅色界面为墨黑、深色界面为浅白，并沿用现有高对比度配色。窗口/应用文件图标仍使用 ICO。输入切换逻辑未改动。

自有图形源码为 `scripts/create_windows_icons.py`，随项目采用 GPL-3.0-only；没有新增第三方素材。编辑图形时安装 Pillow（本机使用 12.3.0），运行：

```powershell
python scripts/create_windows_icons.py
python scripts/create_windows_icons.py --check
```

脚本输出由版本库管理的 ICO、SVG 和 XAML；普通客户端构建直接使用这些文件，不新增 Pillow 依赖。SVG 与 XAML 保留可缩放字形，ICO 对小尺寸浅色轮廓做光学补偿。

验证范围见 [验证记录](../VALIDATION.md)。此设计不改变已发布 0.4.7 的附件或版本声明。
