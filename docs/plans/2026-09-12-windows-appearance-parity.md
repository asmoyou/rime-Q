# Windows 外观对齐 macOS

用户已安装 0.4.0 构建 9121，并指出 Windows 设置和敲敲猫与 macOS 差异过大。此次直接以现有 macOS 源码与产品截图为准，不再另定视觉方向。

1. 迁移 `TypingCat.swift` 的完整 96×64 矢量坐标、配色、身体/尾巴/键盘/肉垫和左右爪 160 ms 姿态。Windows 原生候选和 WPF 预览使用同一 C++ 绘制模块。
2. 候选按 macOS 的字号、行高、内边距、配色和宠物避让规则测量。预编辑留在宿主组合文本中，候选内容不额外保留一行拼音；装饰不增加候选内容尺寸、不接收鼠标。
3. 设置页采用相同灰白/深色基调、204 px 侧栏、28 px 内容边距、分组导航和底部三入口。恢复独立皮肤页，包含动态卡片与六款实际候选预览。
4. 输入页恢复“输入 → 候选显示 → 常用按键 → 快捷输入”的顺序；模型下载与开关同页；字体、皮肤更改即时刷新实际绘制预览。保留 Windows 的系统字体、窗口和操作方式。
5. 检查五页深浅主题、多种尺寸、字号与皮肤选择保存、预览一致性以及候选索引/边缘/隐藏。已安装版本核验启用与服务就绪，真实宿主输入结果单独记录。
6. 构建 9122 安装包，更新验证记录，交付可查看的界面与猫咪图，不提前把安装或真实宿主检查写作通过。
