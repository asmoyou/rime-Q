# Windows 客户端实施计划

**目标：** 提供独立安装的 Windows 10/11 x64 客户端，覆盖 x64/x86 TSF 宿主、简体全拼、原生候选、设置、个人学习、可选模型与安全升级卸载。

**架构：** 原生 C++17 TSF DLL 只处理宿主组合文本、按键和候选 UI；每用户独立的进程外 librime 服务串行管理引擎与词库。两个位数的 DLL 使用同一有界协议，连接按登录用户隔离的本地命名管道。WPF 设置及安装器使用 Windows 自带 .NET Framework 4.8，日常输入无需外部程序或网络。

**技术栈：** MSVC、Windows SDK、TSF/COM、Win32/GDI、librime、WPF、Python 构建脚本。

## 设计取舍

- 采用薄 TSF DLL + 独立引擎服务。直接在每个宿主加载 librime 会重复初始化并争用学习数据；全局键盘监听不能正确管理宿主组合文本，因此不采用。
- 安装包使用版本化程序子目录，避免覆盖宿主仍加载的 DLL。只注册本产品的固定 GUID，保留其他输入法及个人数据。真实文件版本参与降级检查。
- 候选按实际文字与注释测量，支持 DPI、工作区避让、鼠标选词和键盘操作。焦点丢失取消组合，迟到操作不能写到新焦点。
- 设置使用浅色中性底色、青绿色强调、清晰侧栏和可键盘操作的控件；每个后台操作显示运行、成功或具体失败状态。

## 实施顺序及验收

1. **固定资源与构建：** 新增 Windows 依赖锁、资源脚本、独立 CMake 工程及版本资源。校验下载大小/SHA-256、归档路径、许可和雾凇源码；包内禁止 `.gram`。编译 x64/x86。
2. **引擎服务与协议：** 新增 `windows/common` 和 `windows/broker`；隔离用户目录、会话和连接，限制消息长度与超时。实际 librime 验证基础输入、选词、取消、Lua、学习及重启召回。
3. **TSF 与候选：** 新增 `windows/tsf`；注册、激活、写锁、预编辑、提交、显示属性、候选窗口和语言栏菜单。验证未就绪透传、测试键无副作用、组合取消、焦点变化、分页及候选索引。
4. **原生设置与管理：** 新增 `windows/settings`；输入/外观、学习词表管理、模型下载进度/取消/校验/移除、版本与每日检查。后台任务不能干扰输入；配置切换等组合结束。
5. **安装闭环：** 新增 `windows/installer`；单安装入口、版本/构建比较、安装回滚、注册检查、同版修复、卸载确认和保留数据。测试只操作隔离安装，不卸载用户现用输入法。
6. **本机验证和 CI：** 新增协议/服务/TSF 宿主与安装回归，接入 Windows CI。使用专用空白测试窗口进行真实 TSF 输入；已有未受影响的 macOS 检查不重复运行。
7. **交付：** 更新 `docs/WINDOWS.md`、README、第三方声明与 `docs/VALIDATION.md`，记录实际通过项、产物摘要和未验证宿主范围，交付安装包。

本计划直接在当前已授权会话执行。真实宿主、系统启用和安装的结果分别记录；代码存在、COM 注册成功或引擎测试通过均不能替代桌面输入验收。
