# Windows 同步时间与安装器设计

## 目标

让 Windows 用户在同步尚未成功时直接看到可行动的原因，并把安装程序提升为与 macOS 同等完整、但符合 Windows 原生交互习惯的流程。

## 方案

同步页继续以双方应用同一已知版本的签名回执作为成功时间来源，不把连接、传输或单端应用伪装成成功。没有时间时，根据成员状态依次显示旧协议需升级、等待设备连接、等待双方确认或尚未添加设备；设备行显示对应的局部原因。

安装器使用单个 720 x 560 WPF 窗口。左栏固定展示品牌、准备/安装/完成步骤和版本，主区展示离线组件、个人数据保留及管理员认证用途，底部保留明确主操作。覆盖全新安装、升级、同版本、进行中、完成、失败和卸载，跟随 Windows 应用深浅模式和高对比度，不改变既有安装、回滚、启用或卸载逻辑。

## 验证

协调器测试覆盖无时间的四种原因和已有时间优先级；隔离 WPF 测试生成旧协议设备截图并检查文案。安装器测试渲染七种状态的明暗截图，检查固定尺寸、非空像素、控件布局和状态转换。最终执行 Windows 两架构构建、包载荷、安装生命周期、客户端一致性和资源检查；macOS 由同一提交 CI 构建，保持统一产品版本。
