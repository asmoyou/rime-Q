# 后台内存与空闲工作优化

用户已确认按优先级继续实施，并接受同步延迟。保留现有协议、个人目录、恢复语义和手动同步。

1. Windows 设置按需创建，关闭后真正销毁，解除事件订阅与预览/词库对象引用；后台托盘保留。先测量此改动的收益，不引入第二个同时操作同步状态的协调器。设置与后台若分进程，需要额外控制通道及操作串行化；本轮先避免这一可靠性风险。
2. Windows 使用系统事件等待打开/退出请求，后台维护降低到十秒并避免异步重入；可见窗口更新仍独立。共享 Rust 服务用网络 accept、控制/发现通知、最近任务到期时间唤醒，取消半秒空轮询；Mac 父进程检查仍保留有界退出时间。
3. 双端导出采用安静期合并：本机持续学习时最多等待五分钟，停止变化后一分钟再导出；远端待应用、错误恢复与手动操作不受该合并限制。保守 revision 检测继续覆盖删除、部分选择和导入；不以不完整的上屏通知替代学习变更检测。

验证：设置生命周期/重复打开与关闭/异步回调和托盘操作；隔离后台启动和开关窗口后的工作集与私有内存；六服务真实 TLS/手动唤醒/暂停重连/父进程退出；双端合并策略与真实引擎同步安全。完成相关 CI 后按现有授权发布 0.4.7，记录未测项，不替换本机现用输入法。
