# Rime Q 0.4.9

本版修复 Windows 深色开始菜单中 Rime Q 图标仍显示黑色 Q 的问题：应用 EXE 和开始菜单快捷方式使用透明底、纯白 Q 笔画，并新增从 EXE 默认图标提取路径的回归检查。Windows 构建号为 **9151**。

- 保留 Windows 输入源和任务栏入口的纯白图标修复。
- 继续保留个人词库、学习记录、设置及已下载模型。
- Windows 安装包尚未进行 Authenticode 签名；macOS 安装包使用 ad-hoc 签名，尚未完成 Apple Developer ID 签名与公证。

安装包和 SHA-256 文件取自本版同一提交的完整 CI；发布后的公开附件、摘要和更新入口核对记录见 [发布核对](../validation/release-0.4.9-2026-09-29.json)。
