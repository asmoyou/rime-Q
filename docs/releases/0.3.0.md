# Rime Q 0.3.0

Rime Q 的首个公开版本：简洁、流畅、离线的中文输入法。

## 下载与安装

下载本页附件 **RimeQ-0.3.0-macos-universal.pkg**，双击安装后，从菜单栏输入法菜单选择 Rime Q。需要 **macOS 13 或更新版本**，同一安装包包含 Apple Silicon 与 Intel 程序，内置引擎、词库及模型，无需另外安装鼠须管。

升级现有开发版本时会保留个人词库、学习记录和设置。Windows 与 Linux 客户端尚未发布。

## 这一版可以做什么

- 简体全拼、连续组词、空格与数字选词、鼠标选词、翻页和中英文切换。
- 雾凇词库与可选的万象整句优化；输入和学习在本机完成。
- 原生候选栏、四档字号、六款简洁配色，以及趴在候选栏外随按键互动的“敲敲猫”。
- 图形化管理个人学习记录，支持增删改、撤销、搜索、TSV 导入导出；管理内置词表和带全拼编码的第三方词库。
- 日期、时间、农历、计算器、金额大写、Unicode 与 UUID 等快捷输入。
- 重新整理设置排版：统一页面边距与控件对齐，三个快捷键卡片等宽排列；左下角保留使用说明、GitHub 项目、版本与更新入口。
- 默认每 24 小时自动检查一次更新，重启记住检查时间，断网时不反复重试。发现新版在菜单与设置提示，不弹窗打断输入；支持关闭自动检查或随时手动检查，下载和安装由用户决定。
- 随包离线帮助、安装启用处理、同版修复与降级保护；卸载默认保留个人数据。

## 安装说明与当前限制

安装包采用 ad-hoc 签名，**尚未完成 Apple Developer ID 签名与公证**。若 macOS 阻止打开，请确认文件来自本项目，再按“系统设置 → 隐私与安全性”的提示处理。

管理员认证用于写入系统输入法目录；安装器可能请求读取下载文件夹。升级较早开发版本时，可能需要退出旧版 Rime Q。详细用途见[授权说明](https://github.com/asmoyou/rime-Q/blob/v0.3.0/docs/PERMISSIONS.md)。

当前实际宿主测试主要在 Intel Mac 上完成。通用包构建与自动回归不代表已覆盖全部 Apple Silicon 设备、macOS 版本和宿主应用，兼容性验证会继续补充。当前提供简体全拼，双拼及其他平台属于后续计划。

## 构建资源

附件 `wanxiang-lts-zh-hans.gram` 是本版使用的原始万象模型副本，仅供从源码构建使用。作者 amzxyz，来源与 SHA-256 见[依赖锁](https://github.com/asmoyou/rime-Q/blob/v0.3.0/dependencies.lock.json)，按 CC-BY-4.0 保留许可。日常安装只需下载 PKG，模型已包含其中。

## 验证

[GitHub CI](https://github.com/asmoyou/rime-Q/actions/runs/34504930270) 已通过三平台核心构建、macOS 通用构建与完整回归，以及实际 PKG 安装、同版修复、拒绝降级和卸载保留数据检查。无交互运行环境中的启用按明确的待启用/登录重试路径验证，真实宿主兼容性范围见验证记录。

## 文件校验

同时下载 `SHA256SUMS.txt`，在文件所在目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```
