# Rime Q 0.3.1

安装包约 **69.4 MB**，相比 0.3.0 的 441.3 MB 缩小约 **84.3%**。万象语法模型改为按需下载，基础输入和个人学习开箱即用。

## 下载与安装

下载 **RimeQ-0.3.1-macos-universal.pkg**，适用于 macOS 13+，同时支持 Apple Silicon 与 Intel。升级会保留个人词库、学习记录和设置。

安装包采用 ad-hoc 签名，尚未完成 Apple Developer ID 签名与公证。若系统阻止打开，请确认文件来自本项目，再按“系统设置 → 隐私与安全性”的提示处理。

## 万象模型按需下载

- 默认不下载模型。基础组词、个人学习、候选皮肤与日期、计算器等快捷工具均可直接使用。
- 需要整句优化时，进入 **设置 → 输入与外观 → 下载并开启**，下载约 420 MB 的万象模型。
- 提供下载进度、取消和失败重试。文件通过大小与 SHA-256 校验后才启用；下载期间可以继续基础输入。
- 下载后可离线使用。可以关闭整句优化保留模型，或选择 **移除模型…** 释放空间，个人词库和学习记录保留。
- 模型保存在自己的个人数据目录，升级后可继续使用。旧版已开启整句优化且内置模型校验匹配时，安装器会保留已有模型，避免重新下载。
- 未下载或模型校验失败时使用基础组词；模型启用和移除会等待当前输入结束。

每天一次的自动更新检查继续保留，模型仅在用户主动选择后下载。

## 文件校验

可同时下载 `SHA256SUMS.txt`，在文件所在目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```
