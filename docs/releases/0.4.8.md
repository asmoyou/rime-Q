# Rime Q 0.4.8

Windows 图标改为简洁的透明底单色 Q，去掉原来的蓝色方块。深色任务栏的系统输入源图标使用纯白填充笔画，解决黑字加细白边的问题。

- 应用托盘与自有输入法菜单按系统任务栏主题使用白色或深色字形，支持高对比度配色。应用与任务栏的明暗设置可以不同。
- 设置和安装器共用矢量字形，随应用明暗主题显示黑色或浅白色。
- Windows 自己管理的输入源图标使用独立纯白资源；该静态图标不宣称在浅色主题下自动变色。
- 增加默认输入源图标提取、透明像素、多尺寸、混合主题与图标句柄释放检查。

Windows 安装包为 `RimeQ-0.4.8-windows-x64.exe`，构建号 **9149**。macOS 安装包为 `RimeQ-0.4.8-macos-universal.pkg`，本次保持原有图标与输入行为。升级保留个人词库、学习记录、设置及已下载模型。

本机预览构建 9148 已通过真实深色任务栏截图对比。该结果不等同于浅色系统输入源图标或所有宿主的验收；详细范围与证据见 [验证记录](../VALIDATION.md)。

Windows 安装包尚未进行 Authenticode 签名；macOS 安装包使用 ad-hoc 签名，尚未完成 Apple Developer ID 签名与公证。

发布安装包取自 [同一提交的 CI](https://github.com/asmoyou/rime-Q/actions/runs/36293683460)，全部 12 项通过；macOS 构建号为 **1790482505**。macOS CI 验证明确待启用及登录重试分支，不等同于真实宿主立即输入验收。公开附件与更新入口已核对，见 [发布核对](../validation/release-0.4.8-2026-09-27.json)。
