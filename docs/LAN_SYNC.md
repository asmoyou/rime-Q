# 附近设备同步

附近设备同步随 0.4.1 提供，默认关闭。已通过测试与待验证的边界以 `VALIDATION.md` 为准。

Mac 接手续作入口：[剩余工作与真机验收计划](plans/2026-09-13-lan-sync-macos-handoff.md)，包含分支基线、现有测试、原生适配/授权/六设备实测步骤与完成条件。

## 用户操作

在“个人词库 → 附近设备同步”选择“创建同步组”或“加入已有同步组”。Mac 将创建、加入和邀请分成独立引导窗口：正常加入只需要选择附近电脑并输入六位配对码；手动连接默认折叠，可复制/粘贴连接信息。在任意已授权设备点击“添加设备”，新电脑查找并选中该设备，输入原设备显示的六位配对码，再在原设备确认加入。每台电脑加入一次；六台电脑只需五次加入，无须十五次两两配对。邀请码五分钟有效、最多五次尝试，确认等待两分钟。

默认关闭。启用后，已有及后续个人词条、音节分隔的全拼和学习权重在已授权成员间自动合并。个人词条可能包含姓名、专有名词和短句。基础词库包、模型、皮肤、脚本和原始按键不参与同步。无需账号或服务器。

所有成员都可学习、接收和转发；创建者关机不会停止其他成员同步。网络分区期间继续本地学习，重新相遇后补齐。不同城市的电脑没有共同在线或接力路径时，需要等待；纯局域网不提供公网中继。

所有已授权成员都能邀请；**移除设备只能在创建同步组的电脑上操作**。这是成员管理权限，创建者不是数据服务器。此版不支持管理权限转移；创建者丢失或退出后，原组可继续交换已有成员数据，但无法再移除设备，需要在保留本机词库的情况下创建新组。退出会归档同步状态并更换设备身份；其他设备上的旧身份由创建者移除。移除不会远程删除已经复制的词条，离线成员收到撤销后才执行拒绝。

“已应用当前已知变更”要求对端实际写入引擎、回读一致并返回签名回执；只收到网络数据不算完成。离线设备可能有未传出的新词，因此页面不能保证所有电脑实时一致。持续输入时等待组合自然结束。

## 同步频率与资源占用

0.4.7 的 Windows 与 macOS 优先减少后台消耗，不追求实时同步。本机词库停止变化约 60 秒后才导出并合并；持续变化时约每 5 分钟安排一次，仍等待当前拼音组合结束。手动同步、远端变更和未完成任务恢复不受这段合并等待限制，但不会强制提交正在输入的拼音。

没有新变化时，设备间隔约 30 秒联系一次；多设备接力可能需要几分钟。正常的短暂连接使用固定状态区域显示，不反复插入进度行；等待提示在五分钟后才说明等待较久。出现错误时页面仍会显示原因。

共享同步服务按网络事件和任务到期唤醒，不再每半秒轮询；状态查询复用统计结果，无变化时避免重写词库基线。Windows 设置窗口按需创建，关闭后释放页面对象；打开过窗口后仍可能保留 WPF 运行时缓存，不能保证内存立即回到启动水平。具体 CPU、内存样本及测试条件见 [验证记录](VALIDATION.md)，隔离测量不代表整机或所有设备的实际占用。

如果异常退出后实际词库与待应用快照不同，自动写入暂停。Mac 的“更多 → 处理未完成的同步”会先备份本机与目标两份快照，经过用户确认后采用本机当前词库，并向组内传播新增、修改和删除。备份可从“查看同步恢复快照”打开；手动词库的撤销备份不受后台同步覆盖。自动快照在成功回读后按最近 20 份、64 MiB 清理，至少保留一份；最近一分钟的快照暂不清理。手动恢复的两份快照和退出归档不参与自动清理。

## 网络与权限

Rime Q 的同步辅助程序在用户启用功能时监听局域网，查找设备时浏览 mDNS。默认不开启监听或发现；Mac 未开启同步时只打开页面不会启动服务，主动创建或查找设备时才启动仅供当前用户认证访问的回环控制接口。取消本地网络或防火墙授权会影响同步，输入与本机学习继续可用。

服务使用 `_rimeq-sync._tcp.local.`，临时服务标识不包含词条。用户主动打开邀请时会广播自己设置的设备名称，方便多台同平台电脑辨认；日常不广播名称。发现失败可以使用对端显示的连接地址，但仍需配对验证；地址方式不能绕过访客网隔离、VLAN 或防火墙。

本轮按私有/链路本地 IP 范围过滤，自动发现使用 IPv4；**尚未实现公共网络和 VPN 的平台级自动识别及逐接口开关**。启用期间可能使用具有私有地址的 VPN 接口，只在信任的网络开启。此限制不能描述成“自动排除公共网络/VPN”。不做 UPnP、端口映射或公网发现。

TLS 1.3 加密；Ed25519 设备身份签名绑定 TLS exporter，再交换词库。首次加入使用同样绑定通道的 SPAKE2 与 HMAC 验证、一次性码和原设备确认。Windows 私钥使用 DPAPI；macOS 私钥保存到 `~/Library/Application Support/RimeQ/sync/identity.key`，目录权限 `0700`、文件权限 `0600`。文件不额外加密，同一账户下的程序仍可能读取。六位配对码只在内存中保存。传输加密不等于本机学习库全盘加密。

Mac 同步组件不读取、写入或删除 Keychain 项目，也不依赖 `security-framework`。未开启同步时查看页面不创建身份。旧开发版的 `keychain-v1` 标记只用于判定身份已废弃：先归档旧同步状态，再生成新的私有文件身份，需要重新创建或加入同步组，个人词库和学习记录保留。已经使用私有文件的身份在重启、更新后继续复用。启动失败后停止自动重试，可在页面点“重试连接”。

## 合并与落地

- 不复制运行中的 LevelDB。原生客户端是 librime 的唯一写入方，在空闲时通过官方维护接口导出、比较、备份、增量导入并回读。
- 同词不同读音独立保留；同一代次的并发权重取较大值，不累加。因果上更晚的降低权重仍能生效，不声称权重代表精确输入次数。
- 每个来源的签名操作有连续序号、因果版本；重复传输不重复计入，缺口不推进确认水位。
- 删除屏障持久保存。尚未在输入引擎应用删除的旧学习不能复活词条；实际应用删除后重新学习可以产生新代次。
- SQLite 以事务保存收到/处理状态和待应用任务。引擎与同步库不是一个事务；中断后根据原快照、目标快照和实际回读决定继续或提示恢复。
- 回执同时绑定操作版本与成员状态摘要；成员移除后不能用旧回执误报已经应用。
- 密钥、完整网络包和词条正文不写入普通日志。网络请求不能指定文件路径、脚本或配置。

共用服务位于 `sync/`，Rust 工具链和依赖由版本文件与 Cargo.lock 锁定。平台构建脚本打包辅助程序、依赖许可、源版本与校验值。Linux 当前仅提供隔离测试服务，尚未实现正式客户端与系统密钥存储。

## 容量与未完成边界

六设备是基本测试场景，二十容器扩展已通过，五十节点压力测试尚未通过；实际结果见 `VALIDATION.md`。不能根据进程或容器测试宣称已验证相同数量的真机。协议限制为 128 个历史成员身份、20 万个词条键（含保留删除历史）；每帧最多 4 MiB，增量按字节与记录数量分批。记录按原始来源转发；定时任务按最早待检查时间公平调度，避免大量设备时部分成员饥饿。

本轮没有历史检查点压缩、管理权限迁移、设备重命名/搜索和逐词冲突恢复预览。操作日志、手动恢复快照和退出归档会随使用增长，不能承诺无限期无人维护；这些仍是正式商业交付前的工作。安装应用的 macOS 本地网络授权、Windows 防火墙体验、跨平台真机长时间输入与网络切换仍需专项验收，容器与模拟宿主不能代替。

## 隔离测试

`python scripts/test_lan_sync.py --binary sync/target/debug/rimeq-sync[.exe]` 使用六个隔离目录与进程测试真实 TLS；`scripts/test_lan_sync_sandboxes.py` 使用六个独立 Docker 网络/存储命名空间，可通过 `--nodes 20` 或 `--nodes 50` 扩大规模。容器共享内核，不称为六台独立内核虚拟机。专用普通桥接网络允许组播，有默认出站路由；不映射主机数据，不发布端口。

`scripts/test_windows_sync_sandbox.py` 仅向 Windows Sandbox 映射任务构建的只读输入和专用报告目录，在虚拟机内运行真实 librime/TSF 测试，不安装或替换宿主当前输入法。`--isolated` 只接受新测试目录或已有明确测试标记目录，测试身份不能用于正式模式。


## Mac 原生隔离验证

`python3 scripts/build_macos.py --universal --smoke` 现在包含六个 Mac 原生节点测试；仅复测同步可用 `--universal --reuse-resources --sync-smoke`。已有本地开发应用时，也可运行 `python3 scripts/test_macos_sync_native.py --app /path/to/RimeQ.app`，驱动会建立独立 Bundle ID 的临时预览并按确切路径取消注册。

每个节点使用独立 librime 数据目录、测试偏好和辅助进程，执行实际 Swift 适配层、TLS、官方词库导入与回读。辅助进程仅使用回环地址和测试身份，不访问正式 Keychain。此测试关闭 mDNS，因此暂停恢复或辅助进程重启后由驱动刷新测试连接地址；它不等同于局域网自动发现、网络切换或六台真机验收。CI 保存合成场景摘要和六成员窗口截图。

Mac 辅助进程绑定启动它的输入进程；输入进程异常退出后，辅助进程在调度循环中退出并清理控制入口。下一次启动恢复持久同步状态与待应用任务。自动恢复旧任务的回执完成后重新读取引擎，避免沿用等待期间已经变化的快照。窗口保留操作错误、显示邀请过期，并从顶部展示可滚动的成员列表。


Mac 设备页提供搜索和稳定的设备行，状态变化不会重建整个列表；设备移除放在每行的选项菜单，备份、恢复和退出放在“更多”。等待确认时可以取消加入，服务会撤回尚未完成的请求并清理对端待确认项，之后可重新邀请。若对端确认已经完成，以实际加入结果为准，仍可从“更多”退出。邀请窗口显示剩余时间，配对码被使用后停止复制，并将设备确认操作放在窗口前部。

开发渲染入口为 `RimeQ --sync-ui-render 输出目录`，应通过构建脚本的独立预览 Bundle 运行。完整 smoke 和同步 smoke 都保存浅色、深色、小窗口、二十设备及创建/加入/邀请/确认的合成预览；预览图隐藏配对码，不读取个人词库。
