# 词库与模型

基础路线为 librime + 雾凇数据与输入规则 + 经验证的万象能力。Rime Q 统一提供安装、设置和候选界面。

## 当前内置

雾凇固定于 `fbb516b2786e4d5444383706d13c31c2e4d10c08`，按上游 `import_tables` 使用这些中文词表：

| 词表 | 来源文件 | 原始记录行数 |
| --- | --- | ---: |
| 常用字与读音 | cn_dicts/8105.dict.yaml | 8,757 |
| 基础词库 | cn_dicts/base.dict.yaml | 543,088 |
| 扩展词库 | cn_dicts/ext.dict.yaml | 339,185 |
| 腾讯词向量整理词表 | cn_dicts/tencent.dict.yaml | 980,961 |
| 其他补充 | cn_dicts/others.dict.yaml | 905 |

计数排除了头部、空行和注释，包含异读等记录，不等于去重后的不同汉字或词语数量。英文与中英混输表也随包提供。以上记录数不是输入准确率的证明。

万象 LTS 简体语法模型随包内置，体积 420,339,756 字节；“长句优化”模式按雾凇官方配方启用。默认基础模式用于先建立轻量输入基线，两种模式共用学习词典。模型采用内存映射，文件体积不等于常驻物理内存；实际内存和延迟需要分别测量。

当前 Q 方案保留雾凇的拼写、纠错、英文混输、简繁转换、Emoji 与拆字能力，裁剪与日常输入无关的日期、农历、UUID 等翻译器。没有启用雾凇的长词优先与固定候选过滤器，以便先观察原生学习和候选排序；其效果仍需更多真实案例对比。

## 后续补充策略

- 用实际漏词、错音或排序案例建立回归集，再选择新增来源。
- 网络新词、计算机、医学、游戏等按可追溯资源包引入；记录作者、版本、许可与转换方式。
- 对齐拼音、声调、辅助码与中英混合编码；同词不同读音不能简单去重。
- 合并时处理重复词条、异常词频与明显噪声。先做候选质量、体积、部署耗时和输入延迟对比，再决定默认启用。
- 资源只在用户主动更新或导入时变化；日常输入不查询在线词库。个人学习数据不被资源更新覆盖。

万象完整方案及其他专业词库的独立安装/停用界面尚未实现。当前已经吸收万象语法模型，不能据此声称内置了万象全部功能。
