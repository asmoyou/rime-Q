# 词库与模型

基础路线为 librime + 雾凇数据与输入规则 + 经验证的万象能力。Rime Q 统一提供安装、设置和候选界面。

## 当前内置

雾凇固定于 `fbb516b2786e4d5444383706d13c31c2e4d10c08`，按上游 `import_tables` 使用这些中文词表：

| --- | --- | ---: |
| 常用字与读音 | cn_dicts/8105.dict.yaml | 8,757 |
| 基础词库 | cn_dicts/base.dict.yaml | 543,088 |
| 扩展词库 | cn_dicts/ext.dict.yaml | 339,185 |
| 腾讯词向量整理词表 | cn_dicts/tencent.dict.yaml | 980,961 |
| 其他补充 | cn_dicts/others.dict.yaml | 905 |

计数排除了头部、空行和注释，包含异读等记录，不等于去重后的不同汉字或词语数量。英文与中英混输表也随包提供。以上记录数不是输入准确率的证明。

万象 LTS 简体语法模型从 0.3.1 起按需下载，体积 420,340,780 字节（约 420 MB），不再占用安装包。“输入与外观”中的“下载并开启”会下载固定版本模型并校验大小与 SHA-256，再启用整句优化。提供进度、取消、重试和移除入口，默认不会下载。开启后由 librime-octagram 使用万象模型辅助整句组词；关闭时仍有 librime 原生组词、词频与学习。两种状态共用雾凇词库和 rime_q 学习词典，短词的候选可能完全相同，模型也不保证每句话更准确。模型采用内存映射，文件体积不等于常驻物理内存。模型保存在 `~/Library/Application Support/RimeQ/models`，通过 `rime` 目录中的对应链接供引擎读取。首次启动只校验已有文件，不会发起模型下载；未下载或校验失败时使用基础组词。移除模型会关闭整句优化，保留学习记录。

当前 Q 方案保留雾凇的拼写、纠错、英文混输、简繁转换、Emoji 与拆字能力，裁剪与日常输入无关的日期、农历、UUID 等翻译器。没有启用雾凇的长词优先与固定候选过滤器，以便先观察原生学习和候选排序；其效果仍需更多真实案例对比。

## 个人词库

在“设置 → 个人词库”中查看实际的 Rime 学习记录。提供词条/拼音搜索、按学习权重/词条/拼音排序、新增、编辑、批量删除、撤销上次修改，以及 UTF-8 TSV 导入导出。新增时按音节填写全拼，例如 `xing he ci ku`。

学习权重包含导入的权重，不等于真实输入次数；编辑文字或拼音保留学习权重。删除只移除个人记录，内置词库中的同名词仍可能出现。页面按打开和刷新读取，不在后台持续扫描学习库。修改前重新读取受影响记录；如果这些记录已有新的学习，拒绝旧编辑/撤销并提示刷新。

个人操作使用 librime 官方 `levers` API，不直接编辑运行中的 LevelDB。维护前结算正在输入的内容、释放全部会话，下一次输入自动重建会话。修改前的可移植备份位于 `~/Library/Application Support/RimeQ/lexicon-backups/before-last-change.tsv`。撤销记录保留在当前进程内，备份文件跨重启保留。

TSV 每行是“词条、空格分隔的全拼、可选整数学习权重”，各列以制表符分隔。导入合并同词同拼音，保留较高权重；导出包含全部个人记录。拒绝负数删除标记、损坏记录和声明为其他输入方案的学习库；不直接导入 `.userdb` 或二进制快照。

## 内置与第三方词库管理

“设置 → 词库与模型”显示内置资源与第三方词库的条目数、状态、来源、版本、原始许可说明和 SHA-256，可查看词条、搜索并导出源文件。内置字表与基础词库保留为必需资源；扩展词库、腾讯整理词表和其他补充可以启停。英文、中英混输和拆字资源目前随输入能力保留；万象模型由整句优化开关控制。

第三方支持带明确全拼编码的独立 `.dict.yaml` 和 TSV/TXT 文本，每个文件不超过 32 MB、50 万条记录。支持声明 `columns` 的列顺序和非负数值词频，同词同拼音保留较高词频。暂不支持 `import_tables` 合集、无注音词表、声调/双拼/形码、百分比词频、完整方案/Lua 或搜狗 SCEL 等二进制文件。

导入先验证文本并预览数量，再保存名称、来源与许可说明。原始文件和规范化词表保存在 `~/Library/Application Support/RimeQ/dictionaries/imports`；内置条目优先于第三方重复词条。第三方资源可以启用、停用和从列表移除；移除保留源文件和已有个人学习记录。

词库变更在独立辅助进程中编译到新目录，编译期间继续使用旧资源。验证两种状态下的中文候选，并等待当前组合输入结束后，才切换引擎并原子保存配置；失败保留旧配置和学习库。“恢复内置”会备份当前配置、启用内置词库并停用第三方词库。编译只使用内置配置与经过规范化的词条，不执行导入文件携带的输入方案或脚本。

备份完整个人环境时应保留整个 `~/Library/Application Support/RimeQ`，包含学习库、第三方原文件和管理配置。跨机器迁移优先导出/导入个人 TSV 与第三方源文件，并在目标机器重新编译。

## 后续补充策略

- 用实际漏词、错音或排序案例建立回归集，再选择新增来源。
- 网络新词、计算机、医学、游戏等按可追溯资源包引入；记录作者、版本、许可与转换方式。
- 对齐拼音、声调、辅助码与中英混合编码；同词不同读音不能简单去重。
- 合并时处理重复词条、异常词频与明显噪声。先做候选质量、体积、部署耗时和输入延迟对比，再决定默认启用。
- 资源只在用户主动更新或导入时变化；日常输入不查询在线词库。个人学习数据不被资源更新覆盖。

完整万象方案的安装与切换仍在后续范围；当前专业词库通过独立全拼词表导入，不能据此声称内置了万象全部功能。
