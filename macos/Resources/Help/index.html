Rime Q 使用说明

简洁、流畅、离线的中文输入法。引擎和词库随应用安装，日常输入不需要联网。

项目地址：github.com/asmoyou/rime-Q · 版本与下载。源码、使用说明及发布版本均以项目页面为准。

开始使用

从菜单栏的输入法菜单选择 Rime Q。输入全拼，用空格确认候选，也可以用数字键或鼠标选词。单独按下并松开 Shift 切换中英文，Esc 取消当前组合，减号 / 等号或 Page Up / Page Down 翻页。

菜单中的“设置…”采用侧栏导航，提供“输入与外观”“皮肤”“个人词库”“词库与模型”，以及侧栏底部的“版本与更新”。万象模型为可选下载，默认不会下载。在“输入与外观”点击“下载并开启”后，会显示约 420 MB 模型的下载进度，可取消或失败重试；校验通过后才启用。“整句优化（万象语法模型）”开启后辅助整句组词，关闭时使用 librime 原生组词、词频与个人学习；两种状态都使用雾凇词库并共用学习记录，并不是切换完整输入方案。短词候选可能相同，也不保证每句都更准确。设置会在下一次开始输入时生效。你也可以调整候选字号，直接查看预览。窗口可调整大小，内容自动换行或滚动。候选栏采用圆角背景，宽度按当前页的编号、候选文字和注释决定；长句会限制宽度并截断显示。系统启用“减少透明度”时遵循系统的显示方式。

雾凇快捷输入

以下工具已经内置并启用。在中文模式下输入触发码，空格、数字键或鼠标选择结果。触发码区分大小写，整句优化开关的两种状态都可使用。

输入用途
rq / rqzh / rqen当前日期 / 中文日期 / 英文日期
sj / xq当前时间 / 星期
dt / tsISO 日期时间 / 时间戳
nl / N20240210今日农历 / 指定公历日期转农历（1900–2100 年）
cC1+2*3计算器，结果为 7；支持括号和常用数学函数
R123.45数字、金额大写
U62fc按 Unicode 十六进制编码输入“拼”
uuid生成 UUID 标识
[ / ]有候选时取当前候选的首字 / 尾字

同时保留错音错字提示、英文自动大写、部件拆字与符号辅助。脚本来自随包保留版本的雾凇拼音，全部在本机运行。使用第三方词库时，升级会在后台更新输入配置，保留词表选择和学习记录，当前输入结束后再生效。

选择候选皮肤

进入“设置 → 皮肤”，简洁皮肤提供随系统、纸白、雾蓝、青玉、浅樱、暮色六款配色；高级皮肤以独立的大卡片展示敲敲猫等动态效果，可以先试敲再选择。选择后自动保存，下次输入时生效。候选顺序和学习记录不受皮肤影响。

“随系统”使用原生半透明材质，随系统的深浅模式变化，并遵循“减少透明度”。其他皮肤采用固定配色；“暮色”适合偏好深色候选背景的用户。皮肤选择只影响候选栏，设置窗口遵循系统外观。

“敲敲猫”趴在候选栏上边缘外侧，随输入按键交替敲键盘，停止输入后回到静止状态。小猫不占候选内容的空间，也不拦截鼠标点击。点击高级皮肤卡片的“试敲一下”可预览动作。开启系统“减少动态效果”后，小猫保持静止。动画不采集或保存输入内容，也不会在候选栏关闭后持续播放。

安装后还没出现

升级或同版修复时，会先切离 Rime Q，刷新它的简体模式和父输入法，再重新注册、启用。这个过程只调整 Rime Q 的启用状态，个人词库和学习记录保留。

安装会分别检查输入源启用与新版输入服务。成功后由安装进程接续提供输入，通常无需注销。若遇到升级后菜单或候选没有出现，个人数据文件夹内的 installation.log 保留安装与服务启动记录，反馈时可提供对应时间段；“已启用”标记本身不代表输入服务已经完成接管。

安装后会在后台自动启用，成功时不需要额外确认。只有“尚未启用”时才会弹出提示，可以选择稍后处理，或保存工作后注销并重新登录。下次登录会自动重试一次。启用成功时无需注销或重启。

也可以打开“系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文”，查找 Rime Q。

为什么会请求授权

  • 安装器要求管理员认证：把应用安装或更新到系统输入法目录。取消后本次安装不会继续。卸载系统目录中的应用也需要认证。
  • 安装器访问下载文件夹：读取你下载的安装包。拒绝后可能无法读取本次安装包；日常输入不需要访问下载文件夹。这个提示由 macOS 安装器显示，可能早于包内介绍页。
  • 控制 Rime Q：升级时关闭仍在运行的旧版进程，让新版接管输入。新版优先通过自身的更新退出机制完成；兼容较早版本时仍可能出现这个请求。拒绝后无法自动退出旧版，可以稍后完成升级。
  • 注销确认：只在你明确选择“注销账户…”后请求系统确认。可以取消或选择稍后处理。

选中 Rime Q 时，按键和候选转换在本机处理，学习记录保存在本机。更新检查只查询公开发布信息，不发送输入内容。每项授权应对应具体操作，不能把不明来源的授权全部当成安装必需项。

查看版本与升级

“关于 Rime Q…”和“设置 → 版本与更新”显示当前版本与构建号。安装包会检测系统目录中的实际版本，自动选择首次安装、升级或同版修复；升级和修复保留个人词库与设置。较旧的版本或构建不会覆盖新版。

可选万象模型

基础输入、个人学习和快捷工具无需下载模型。需要辅助整句组词时，可在“设置 → 输入与外观”下载并开启万象模型，约 420 MB。下载不影响基础输入，支持取消和失败后重新下载；文件必须通过大小与 SHA-256 校验，启用会等待当前输入结束。下载后不需要联网使用。可以关闭整句优化保留模型，也可以选择“移除模型…”释放空间。

模型文件保存在 ~/Library/Application Support/RimeQ/models/wanxiang-lts-zh-hans.gram，rime 目录中的同名文件只是链接。按 0.3.1 及后续版本下载后，升级、重装 Rime Q 或关闭整句优化均会保留模型；同一模型版本只下载一次，启动后在本地校验并复用。只有主动移除、文件缺失或损坏，或之后选择升级模型本身时才需重新下载。个人词库与学习记录独立保留。

检查更新

默认每 24 小时在后台查询一次 GitHub 公开发布信息，重启应用也保留检查间隔；检查失败同样等待下一周期。发现新版本会在输入法菜单和“设置 → 版本与更新”提示，后台检查不会弹窗打断输入。可在该页面关闭自动检查，也可随时从菜单手动“检查更新…”。网络错误、尚无公开版本和没有更新会分别显示。下载与安装由你决定。

发布页面 · 反馈问题

卸载

在菜单中选择“卸载 Rime Q…”，确认后会切换到其他输入法并移除应用。系统安装需要 macOS 管理员认证。卸载默认保留个人词库和学习记录。

手动卸载

  1. 先切换到其他输入法，在“系统设置 → 键盘 → 文本输入 → 编辑”中选中 Rime Q，点击减号移除。
  2. 在访达中按 Shift–Command–G，前往 /Library/Input Methods，把 RimeQ.app 移到废纸篓，按系统提示完成认证。
  3. 如果使用的是本地开发安装，应用位于 ~/Library/Input Methods/RimeQ.app。只移除 Rime Q。
  4. 若此前提示过等待启用，检查 ~/Library/LaunchAgents，移除存在的 com.asmoyou.rimeq.activation.plist，取消后续自动重试。
  5. 如果菜单仍显示旧条目，保存工作后注销并重新登录，让系统刷新列表。

管理个人学习记录

进入“设置 → 个人词库”，可以按词条或拼音搜索，按学习权重、词条或拼音排序，并新增、编辑、批量删除、撤销、导入或导出学习记录。拼音按音节用空格分隔，例如 xing he ci ku。打字产生的新记录通过“刷新”读取。

学习权重包含导入权重，不等于实际输入次数。删除只移除个人记录，内置词库中的同名词仍可能出现。编辑保留原学习权重；词条已有新学习时，会提示刷新，避免覆盖。最近一次修改前的 TSV 备份可以通过“查看备份”打开，撤销记录在当前进程内保留。

导入和导出采用 UTF-8 TSV：每行的词条、全拼、可选整数权重以制表符分隔。导入与当前记录合并，同词同拼音保留较高权重；导出包含全部个人记录。

管理内置与第三方词库

“设置 → 词库与模型”可以查看资源数量、状态、来源、版本和许可说明，查看并搜索词条、导出源文件。字表与基础词库是必需资源；扩展词库、腾讯整理词表和其他补充可以启停。万象模型为可选资源，可通过“管理模型…”进入下载、启停和移除页面。

“导入第三方词库…”支持带明确全拼编码的独立 .dict.yaml 或 TSV/TXT 文件，单文件不超过 32 MB、50 万条词条。暂不支持仅引用其他文件的 import_tables 合集、无注音、声调、双拼或形码词表，以及 SCEL 等二进制文件；请先转换为全拼文本。导入会保留原文件及其中的作者声明，可以补充资源名称、来源和许可。

导入或启停词库后会自动编译，成功后等待当前输入结束再使用新词库；编译期间可以继续打字，失败时继续使用原词库。第三方词库可停用或移出加载列表，个人学习记录会保留。“恢复内置…”先备份配置，再启用内置词库、停用第三方词库。出现自定义词库加载异常时，可重新应用词库或恢复内置配置。

个人数据与备份

菜单中的“打开个人数据文件夹”可以找到自己的数据。学习词库位于 ~/Library/Application Support/RimeQ/rime。第三方原文件及管理配置位于同级的 dictionaries，个人修改备份位于 lexicon-backups，可选模型位于 models。完整备份请保留整个 ~/Library/Application Support/RimeQ。跨机器迁移可导出个人 TSV 和第三方源文件，在目标机器重新导入、编译。卸载应用不会删除它，也不会删除鼠须管或其他输入法的数据。
